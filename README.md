## Running Any Lab Locally

Each lab directory is self-contained with its own dependencies and configuration:

```bash
# Navigate into the target lab folder
cd lab-01   # or lab-02, lab-03

# Install dependencies
npm install

# Start the application
npm start       # or npm run dev
```

For detailed endpoints, parameter documentation, screenshots, and viva solutions, visit the respective `README.md` inside each lab folder.
